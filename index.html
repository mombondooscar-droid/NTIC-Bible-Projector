NAGAD Bible

"Rendre Christ plus proche." — Devise NAGAD · 1 Pierre 4:10

Application de projection biblique gratuite pour les cultes. Projet NAGAD — ICC Brazzaville. Pilotez l'affichage en temps réel sur un projecteur depuis n'importe quel appareil sur le réseau local — smartphone, tablette ou PC.
Aucune connexion Internet requise.

  • Projection plein écran des versets (/projection-bible)
  • Lower Third compatible OBS/VMix (/projection-lt-verset)
  • Gestion des chants avec paroles et traduction
  • Plus de 30 versions simultanées (FR, EN, Lingala, Kituba…)
  • Modes bilingue et explicatif pour une double projection
  • Mode diapositive plein écran avec taille de police adaptative
  • Fonctionne hors ligne (PWA — Progressive Web App)

🌐 Réseau & Sauvegarde

🌐 Mode réseau

Le mode serveur est activé automatiquement lorsque le serveur central est détecté. Toutes les données sont synchronisées avec le serveur.

Statut ${App.settings?.serverMode ? '🟢 Connecté au serveur' : '🔴 Mode local (hors ligne)'} (détection automatique)
${App.settings?.serverMode ? '✅ Connecté' : '⏳ En attente de connexion...'}

📡 Relais réseau (projection)

Synchronise les projecteurs entre appareils différents (PC, téléphone, tablette) et avec OBS Studio. Nécessite le serveur local server.py (lancez start.bat ou start.sh).

—
Adresse locale : localhost
OBS Browser Source :
http://localhost:8080/projection-bible.html
Remplacez localhost par l'IP ci-dessus pour un accès depuis un autre appareil du réseau.
📺 Guide OBS Studio
  1. Lancer le serveur (double-clic sur start.bat)
  2. Ouvrir OBS Studio
  3. Ajouter une Source Navigateur
  4. URL : http://localhost:8080/projection-bible.html
  5. Dimensions : 1920 × 1080
  6. Répéter pour projection-chant.html, projection-lt-verset.html, etc.
